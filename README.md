# EDA-projects
ConnectTel Telecom faces a significant challenge with customer churn, which poses a threat to its growth and profitability. Existing customer retention strategies have proven ineffective, resulting in the loss of valuable customers to competitors.

To address this issue, this project aims to build a robust system leveraging data analysis and machine learning to predict customer churn. By accurately identifying customers at risk of leaving, ConnectTel can implement targeted interventions, such as personalized offers and improved service, to enhance customer satisfaction and loyalty. This initiative will help the company retain more customers, strengthen its competitive edge, and ensure sustainable growth in the dynamic telecommunications industry.

### Objectives
- Accurately predict customer churn.
- Identify key factors driving churn.
- Enable data-driven retention strategies.
- Improve customer retention rates.

### Dataset Description
The dataset includes customer demographics, service usage, account details, and churn labels. Key features include:

- Demographics: Age, gender, location.
- Usage: Monthly charges, tenure, data usage.
- Churn Indicator: Whether the customer churned

### Approach
- EDA: Identify trends and key churn drivers.
- Preprocessing: Handle missing values, encode categorical variables, and scale features.
- Modeling: Test and optimize models like Logistic Regression, Random Forest, and XGBoost.
- Evaluation: Use metrics like ROC-AUC, accuracy, and recall to select the best model.

 ### Results
- Model Performance: Achieved 90% ROC-AUC and 90% accuracy.
- Key Churn Drivers: High monthly charges, short contracts, unresolved complaints.
- Insights: Customers on month-to-month plans with frequent support interactions are at higher risk of churn.

  ### Tech Stack
- Python Libraries: pandas, numpy, scikit-learn, XGBoost, seaborn, matplotlib.
- Tools: Jupyter Notebook for data analysis and model development.
